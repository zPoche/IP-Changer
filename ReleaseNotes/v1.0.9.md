## ProfileIpSwitcher v1.0.9

### Download

- **ZIP:** `ProfileIpSwitcher-v1.0.9-win-x64-self-contained.zip` – portable, self-contained x64-EXE (ohne separates .NET-8-Setup).
- **Hinweis:** Als **Administrator** starten, damit IP-/DNS-Änderungen angewendet werden können.

### Änderungen seit v1.0.8

#### Neu: IP-Ping im Hauptfenster

- Im Bereich **Aktueller Adapter (Live)** gibt es jetzt eine neue **IP-Ping**-Zeile.
- Eingabe einer IPv4-Zieladresse (z. B. `8.8.8.8`) und Start per **Ping starten**.
- Während des Ping-Laufs zeigt die UI einen Busy-Indikator; der Start-Button ist in dieser Zeit deaktiviert.
- Das Ergebnis wird direkt im Fenster angezeigt (Antwortzeit in ms oder Fehler-/Timeout-Status).

#### Technisch

- Ping-Logik asynchron im `MainViewModel` mit `System.Net.NetworkInformation.Ping`.
- IPv4-Validierung vor dem Senden über vorhandene `IPv4Validation`.
- Status-/Ergebnistexte und Logging für erfolgreiche und fehlgeschlagene Ping-Versuche.

### Bekannte Einschränkungen

- Windows x64; WPF-App ist weiterhin nicht unter Linux lauffähig.
- Der Ping-Dialog erwartet eine IPv4-Adresse (IPv6 ist in diesem Feature nicht vorgesehen).
